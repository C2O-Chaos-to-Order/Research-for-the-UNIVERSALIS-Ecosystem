## objective_question

## method_summary

Construct a contracting family whose residual is exactly 1/4 and whose Lipschitz constant is 1/2, iterate five steps in exact rational arithmetic, and compare the true error to the bound step by step.

## assumptions

X is the real plane and Y the real line, all quantities dimensionless, d_Y the absolute difference, and phi the arithmetic mean, matching the tablet's own worked example in section 5. Delta is taken as F_Y(phi(x)) minus phi(F_X(x)) in absolute value. All arithmetic is exact rationals, so no floating-point tolerance is involved. The declared domain is treated as a closed box in both coordinates.

## acceptance_or_falsification_criteria

Acceptance: the true error equals the bound at every step, so the ratio is exactly 1 and the bound is sharp. Falsification: any step where the ratio is strictly below 1, which would show the bound is not tight for this family.

## actual_conditions

Deterministic exact-rational computation. No network, no random sampling, no external service. Cases run in separate subprocesses against a hash-locked model file.

## outcome_summary

The error equalled the bound exactly at every step: 0, 1/4, 3/8, 7/16, 15/32, 31/64, with ratio 1 throughout. The closed form is sharp for this family.

## uncertainty_and_limitations

Sharpness is shown for a constant residual only. Whether the bound is attained when the residual varies with x is not tested. The family was chosen because its residual is exactly computable, not because it resembles a real system.
