## method_summary

Recompute every row of the published evidence table from the two stated fixture models and compare discrepancy and pass/fail value for value. A separate adversarial control repeats the comparison against a copy with one value corrupted.

## assumptions

X is the real plane and Y the real line, all quantities dimensionless, d_Y the absolute difference, and phi the arithmetic mean, matching the tablet's own worked example in section 5. Delta is taken as F_Y(phi(x)) minus phi(F_X(x)) in absolute value. All arithmetic is exact rationals, so no floating-point tolerance is involved. The declared domain is treated as a closed box in both coordinates.

## acceptance_or_falsification_criteria

Acceptance: all 50 rows reproduce, and the corrupted copy yields exactly one detected mismatch naming the altered row. Falsification: any row that does not reproduce, or a corrupted copy that passes.

## actual_conditions

Deterministic exact-rational computation. No network, no random sampling, no external service. Cases run in separate subprocesses against a hash-locked model file.

## outcome_summary

All 50 rows reproduced with zero mismatches. The corrupted copy produced exactly one mismatch, on row TR-01, and the case correctly failed.

## uncertainty_and_limitations

This reproduces the tablet's arithmetic from its own formulas. It tests no scientific claim, and reproducing a published table is not independent verification of it. The grid enumerates starting points that were evaluated; it does not define a state space that the transformation is guaranteed to stay inside. That distinction is central to this package.
